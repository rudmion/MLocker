# MLocker — Менеджер паролей (Desktop App)

## Общая информация

**Название:** MLocker  
**Тип:** Десктопное приложение — менеджер паролей  
**Версия:** 1.6.1  
**Язык интерфейса:** Русский

## Стек технологий

### Frontend

- **Фреймворк:** React 19 + TypeScript
- **Сборщик:** Vite 7
- **Стили:** Tailwind CSS 4 + shadcn/ui
- **Состояние:** Zustand
- **UI-компоненты:** shadcn/ui (Sidebar, Dialog, Sheet, Command, Tabs, Switch, Button, Input, Card, Tooltip, Toast/Sonner и др.)
- **Шрифт:** Geist Variable (`@fontsource-variable/geist`)
- **Иконки:** Lucide React

### Backend (Desktop-слой)

- **Фреймворк:** Tauri 2 (Rust)
- **Язык:** Rust
- **Пакеты:** tokio, serde_json, pbkdf2, sha2, aes-gcm, reqwest, rand, base64, sanitize-filename, tauri-plugin-shell, tauri-plugin-single-instance, tauri-plugin-updater, tauri-plugin-process

### Хранение данных

- Файл `data.json` сохраняется в папку `%APPDATA%/my-password-manager/`
- Фавиконки сохраняются в `%APPDATA%/my-password-manager/favicons/`
- Настройки пользователя хранятся в `localStorage` (ключ `mlocker-settings`)

## Модель данных

### Типы данных (TypeScript)

```typescript
type CustomField = {
  id: string;
  key: string;
  label: string;
  value: string;
  hidden: boolean;
};

type Entry = {
  id: string;
  createdAt: string;
  updatedAt: string;
  iconUrl: string | null; // путь к фавиконке
  title: string;
  description: string;
  url: string;
  favourites: boolean;
  login: string;
  password: string;
  loginUpdatedAt: string;
  passwordUpdatedAt: string;
  securityLevel: number; // 1 = слабый, 2 = средний, 3 = сильный
  customFields: CustomField[];
};

type Section = {
  id: string;
  createdAt: string;
  name: string;
  entries: Entry[];
  icon: string;
};

type DataFile = {
  sections: Section[];
  master_hash?: string; // хэш мастер-пароля
  salt?: string; // соль для хэша пароля
  recovery_key_hash?: string; // хэш ключа восстановления
  recovery_key_salt?: string;
  encryption_salt?: string; // соль для шифрования данных
};
```

### Формат файла `data.json`

- Хранится в `%APPDATA%/my-password-manager/data.json`
- Формат: JSON с pretty-print
- При включённом мастер-пароле:
  - Поля `login`, `password` и значения `customFields.value` зашифрованы AES-256-GCM
  - Поля `master_hash`, `salt`, `recovery_key_hash`, `recovery_key_salt`, `encryption_salt` содержат хэши и соли
- При выключенном мастер-пароле:
  - Все поля хранятся в открытом виде
  - Поля хэшей отсутствуют

## Криптография (Rust Backend)

### Хэширование пароля

- **Алгоритм:** PBKDF2-HMAC-SHA256
- **Итерации:** 200 000
- **Длина соли:** 16 байт
- **Длина ключа:** 32 байта (256 бит)
- Хэш и соль хранятся в base64

### Шифрование данных

- **Алгоритм:** AES-256-GCM
- **Ключ:** выводится из мастер-пароля через PBKDF2 с отдельной солью (`encryption_salt`)
- **Nonce:** 12 байт, генерируется случайным образом для каждого поля
- Зашифрованные данные: nonce (12 байт) + ciphertext, всё в base64

### Ключ восстановления

- Формат: 4 блока по 4 цифры, разделённые пробелами (например: `1234 5678 9012 3456`)
- Хэшируется так же, как мастер-пароль (нормализация — удаление пробелов)
- Используется для сброса мастер-пароля

### Безопасность

- Сравнение хэшей — constant-time (для защиты от timing-атак)
- Ключ шифрования хранится в оперативной памяти (AppState на Rust)
- Все крипто-операции выполняются в `spawn_blocking` (не блокируют event loop)

## Функциональность

### 1. Аутентификация

#### Создание мастер-пароля (первый запуск)

- Ввод пароля (от 4 до 16 символов)
- Подтверждение пароля
- Автоматическая генерация ключа восстановления (4 блока по 4 цифры)
- Ключ показывается один раз, можно скопировать
- После сохранения — вход в приложение

#### Вход в приложение

- Ввод мастер-пароля
- При неверном пароле — блокировка на 1 минуту после исчерпания попыток
- Кнопка «Забыли пароль?» → восстановление через ключ восстановления

#### Восстановление доступа

- Два шага: ввод ключа восстановления → установка нового пароля
- Ключ ввода по 4 символа в каждом поле (4 поля)
- Поддержка вставки из буфера обмена (16 цифр)
- Автоматическая навигация между полями

#### Настройка мастер-пароля

- В настройках можно включить/отключить мастер-пароль
- При отключении — подтверждение через AlertDialog с предупреждением о рисках
- При отключении мастер-пароля: данные дешифруются и сохраняются в открытом виде, хэши удаляются

### 2. Разделы (Sections)

#### Создание раздела

- Кнопка «+» в нижней части боковой панели
- Dialog с полем ввода названия
- Уведомление о создании (toast)

#### Навигация по разделам

- Боковая панель (Sidebar) с collapsible-режимом (иконка/раскрытый)
- Вариант отображения: floating
- Кнопка «Все записи» для просмотра всех записей

### 3. Записи (Entries)

#### Создание записи

- Кнопка «+» в шапке (доступна только при выбранном разделе)
- Горячая клавиша: Ctrl + +
- Dialog с полями:
  - **Наименование** (обязательное)
  - **URL** (необязательный) — при вводе URL автоматически скачивается фавиконка сайта
  - **Логин** (обязательный)
  - **Пароль** (обязательный) — с кнопкой генерации и показом/скрытием
  - **Описание** (необязательный, макс. 300 символов, с счётчиком)
- Индикатор сложности пароля (круговая диаграмма): слабый/средний/сильный
- Валидация обязательных полей

#### Просмотр записей

- Карточки с:
  - Иконкой звёздочки для добавления в избранное
  - Фавиконкой сайта (или стандартной иконкой)
  - Названием (с усечением и тултипом)
  - Кнопкой открытия ссылки
  - Иконкой уровня безопасности (щит)
  - Кнопками копирования логина и пароля (с анимацией при наведении)
  - Кнопкой открытия инспектора (стрелка вправо)
- Записи сортируются: избранное сверху

#### Редактирование записи (Инспектор)

- Открывается справа в Sheet-панели
- Все поля записи (title, description, url, login, password)
- Кастомные поля: добавление, редактирование, удаление, скрытие значений
- Копирование значений в буфер обмена
- Скачивание фавиконки при изменении URL
- Индикатор безопасности пароля в реальном времени
- Кнопка удаления записи (с подтверждением через Dialog)
- Кнопка сохранения (доступна только при наличии изменений)
- Кнопка «+ поле» для добавления кастомного поля
- Auto-save: данные сохраняются через 300 мс после изменений (debounce)

#### Удаление записи

- Диалог подтверждения (DeleteDialog)
- Toast-уведомление об успешном удалении

### 4. Поиск записей (Command Menu)

- Открытие: Ctrl + S
- Поиск по названию, логину и URL
- Группировка по разделам
- Кнопки копирования логина и пароля в каждой записи
- Toast-уведомление при копировании

### 5. Статистика

#### StatsCards — две карточки:

1. **Всего записей** — общее количество записей (в выбранном разделе или всех)
2. **Слабые пароли** — количество записей с securityLevel ≤ 1

#### Пустое состояние

- Если записей нет — отображается EmptyRecord с иллюстрацией

### 6. Генератор паролей

#### Параметры генерации (настраиваются в Settings):

- Длина: от min (кол-во активных наборов) до 64 символов (слайдер ± кнопки)
- Наборы символов: заглавные, строчные, цифры, символы (переключатели)
- По умолчанию: длина 20, все наборы включены

#### Особенности генерации:

- Используется `crypto.getRandomValues` для криптографически стойкой случайности
- Каждый активный набор гарантирует хотя бы один символ
- Распределение символов случайное

#### Превью в настройках:

- Живое превью сгенерированного пароля (крупный моноширинный шрифт)

### 7. Фавиконки

- Скачиваются с сайта при вводе URL
- Источники (по приоритету): `{scheme}://{domain}/favicon.ico`, `{scheme}://{domain}/favicon.png`, `www.{domain}/favicon.ico`
- Сохраняются в `%APPDATA%/my-password-manager/favicons/`
- Безопасное имя файла через `sanitize-filename`
- Поддержка форматов: PNG, SVG, JPEG, WEBP, ICO
- Проверка content-type

## Особенности реализации

### Автосохранение (debounce)

- Все изменения в записях и разделах автоматически сохраняются
- Задержка 300 мс после последнего изменения
- Флаг `isSaving` для отображения spinner

### Управление состоянием (Zustand)

- `useStore` — основное хранилище (данные, выбранный раздел, инспектор)
- `useSettingsStore` — настройки с персистентностью в localStorage
- `useCreateRecordDialogStore` — состояние диалога создания записи

### Безопасность паролей

- 3 уровня безопасности: слабый (≤3 символов), средний (4-5), сильный (≥6)
- Длина пароля влияет на level
- Индикатор отображается в форме создания и в инспекторе

### Single Instance

- Только один экземпляр приложения может быть запущен
- При попытке запуска второго — фокус передаётся первому окну

### АНИМАЦИИ И ЭФФЕКТЫ

1. **Scroll-reveal:** все секции появляются с fade-in + slide-up при скролле (Framer Motion)
2. **Staggered animation:** карточки появляются по очереди с задержкой 100мс
3. **Hover-эффекты:** карточки поднимаются на 4px, добавляется тень и лёгкое свечение
4. **Gradient text:** заголовки с градиентным текстом (indigo → violet)
5. **Glow-эффекты:** фоновые градиентные пятна с blur (opacity 10-15%)
6. **Smooth scroll:** плавная прокрутка по якорям
7. **Button hover:** градиент сдвигается, кнопка слегка увеличивается
8. **Input focus:** акцентная рамка при фокусе

### ТИПОГРАФИКА

- **Заголовки (h1-h3):** Bold/Semi-bold, Geist Variable, tracking-tight
- **h1:** 4rem (64px), line-height 1.1
- **h2:** 2.5rem (40px), line-height 1.2
- **h3:** 1.5rem (24px)
- **Body:** Regular, 1rem (16px), line-height 1.6
- **Small:** 0.875rem (14px), line-height 1.5

### АДАПТИВНОСТЬ

- **Desktop (1200px+):** полная сетка 3 колонки
- **Tablet (768-1199px):** 2 колонки
- **Mobile (< 768px):** 1 колонка, уменьшенные шрифты, hamburger-меню
- **Small mobile (< 480px):** ещё меньше отступы, h1 уменьшен до 2.5rem

### ДОПОЛНИТЕЛЬНЫЕ ТРЕБОВАНИЯ

1. **SEO:** правильные meta-теги, Open Graph, description
2. **Performance:** lazy-loading изображений, оптимизированные анимации
3. **Accessibility:** aria-labels, keyboard navigation, contrast ratio ≥ 4.5:1
4. **No placeholder-текст:** весь текст должен быть осмысленным и готовым к публикации
5. **Code quality:** чистый, читаемый код с комментариями
6. **Components:** каждый блок — отдельный React-компонент
7. **Theme toggle:** переключатель светлой/тёмной темы с сохранением в localStorage
8. **Smooth transitions:** плавное переключение тем (0.3s)
