# Миграция на official Tauri Updater Plugin

## Цель

Заменить кастомный updater (`src-tauri/src/updater.rs`) на official `tauri-plugin-updater`. Получим:
- Автоматический exit на Windows перед установкой (больше никаких двойных экземпляров)
- Верификацию подписи (minisign)
- Встроенный прогресс загрузки
- Кросс-платформенность без ручного кода

## Файлы для изменения

| Файл | Действие |
|------|----------|
| `src-tauri/Cargo.toml` | Добавить `tauri-plugin-process` |

## Шаги

### 1. Cargo.toml — добавить зависимости

```toml
tauri-plugin-process = "2"
```

`tauri-plugin-updater` уже есть в dependencies.

### 2. tauri.conf.json — обновить конфиг

```json
{
  "bundle": {
    "createUpdaterArtifacts": true
  },
  "plugins": {
    "updater": {
      "pubkey": "...",
      "endpoints": ["..."],
      "windows": {
        "installMode": "passive"
      }
    }
  }
}
```

### 3. capabilities/default.json — добавить permissions

```json
{
  "permissions": [
    "updater:default",
    "process:default"
  ]
}
```

### 4. main.rs — переписать

Убрать:
- `mod updater;`
- `updater::check_for_update`
- `updater::download_update`
- `updater::install_downloaded_update`

Добавить плагины:
```rust
.plugin(tauri_plugin_updater::Builder::new().build())
.plugin(tauri_plugin_process::init())
```

Добавить новые команды:
- `check_update` — проверка обновления через official API
- `install_update` — скачивание и установка через official API

### 5. package.json — добавить JS зависимости

```bash
yarn add @tauri-apps/plugin-updater @tauri-apps/plugin-process
```

### 6. useUpdateChecker.tsx — переписать на official API

```typescript
import { check } from '@tauri-apps/plugin-updater';
import { relaunch } from '@tauri-apps/plugin-process';

// check() возвращает Update object или null
// update.downloadAndInstall(callback) — скачивание с прогрессом
// relaunch() — перезапуск
```

### 7. Удалить updater.rs

Больше не нужен — всю логику берёт на себя плагин.

## Поток обновления (после миграции)

```
1. Frontend вызывает check() → Get update info
2. Пользователь нажимает "Обновить"
3. update.downloadAndInstall(callback) → скачивание + установка
4. На Windows: плагин автоматически завершает приложение
5. NSIS installer перезаписывает файлы
6. relaunch() → запуск обновлённой версии
```

## Верификация

1. `yarn install` — установить JS зависимости
2. `cargo build` — проверить что Rust компилируется
3. Запустить приложение → Проверить обновления → Установить
4. Ожидаемое: приложение закрывается, NSIS ставит новую версию, приложение перезапускается
