# Plan: Auto-Update System Redesign for MLocker

## Overview
Replace the modal update dialog with a non-modal bottom-right notification. Add proper install progress with path display, and soft restart via Tauri's `app.restart()` API.

## Files to Modify

### 1. `src-tauri/src/updater.rs` — Backend
- **Add `restart_app` command**: calls `app.restart()` (confirmed available in Tauri 2.11.0)
- **Add `get_install_path` command**: returns `app.path().resource_dir()` (confirmed available)
- **Modify `install_downloaded_update`**:
  - Remove `app.exit(0)` — app stays running
  - Remove `thread::sleep(2s)`
  - Spawn installer in background thread via `tokio::task::spawn_blocking`
  - Emit `update-progress` events with `{status: "installing", downloaded: 0, total: 0, installPath: "C:\...\MLocker\"}` during install
  - After installer exits, emit `update-status` event with `{status: "installed"}`
  - Return immediately so frontend can track completion via events

### 2. `src/hooks/useUpdateChecker.tsx` — State machine
New states: `idle → checking → hasUpdate → downloading → downloaded → installing → installed (needsRestart)`

Changes:
- Add `installing: boolean`, `installProgress: number (0-100)`, `installPath: string`, `needsRestart: boolean`
- `dismissed` state resets on app restart (React state = per-mount)
- `checkForUpdate(false)` on mount: checks silently, sets `hasUpdate` but doesn't force-show if `dismissed`
- `checkForUpdate(true)` from Settings: always shows result (resets `dismissed`)
- Add `restartApp()` → invokes `restart_app`
- Listen for `update-status` event with `{status: "installed"}` → set `needsRestart = true`

### 3. `src/components/update/UpdateNotification.tsx` — NEW FILE
Non-modal floating card, `position: fixed; bottom: 16px; right: 16px;`, z-index above everything.

States:
- **Available**: Version info, "Обновить сейчас" button, X close, changelog
- **Downloading**: Progress bar with percentage
- **Installing**: Spinner/progress bar, install path text (`Установка в: C:\...\MLocker\`)
- **Installed (needs restart)**: "Обновление установлено" message, "Перезапустить" button

Styling: rounded card with shadow, matches dark/light theme, slide-in animation.

### 4. `src/App.tsx` — Integration
- Replace `<UpdateDialog>` with `<UpdateNotification>`
- **Gate notification on `masterState === 'unlocked'`** — notification only renders when user is logged in
- Pass all useUpdateChecker props to notification

### 5. `src/components/update/UpdateDialog.tsx` — DELETE

## Key Behaviors

### Check Timing
- `useUpdateChecker` calls `checkForUpdate(false)` on mount (silent)
- Notification only rendered when `masterState === 'unlocked'` in App.tsx
- Flow: app opens → master key → unlock → notification appears if update available
- Periodic 4-hour check remains

### Dismiss
- React state resets on unmount (app restart)
- When dismissed: `hasUpdate && !dismissed` = hidden
- Next launch: `dismissed = false`, notification reappears
- Settings "Check for updates" always resets `dismissed`

### Install Path
- Backend: `app.path().resource_dir()` returns e.g. `C:\Users\...\AppData\Local\MLocker\`
- Included in `update-progress` event with `status: "installing"`
- Displayed in notification during install

### Soft Restart
- `app.restart()` in Tauri 2 — restarts process in-place without closing window
- Triggered by "Перезапустить" button after install

### Old Version Cleanup
- NSIS /S installer overwrites files in the same directory
- Old version files are replaced by new ones automatically

## Verification

4. Settings → "Check for updates" → works regardless of dismiss
