# Исправление: обновление уведомлений при проверке обновлений

## Проблема
Пользователь видит старое сообщение "Ошибка проверки обновлений" вместо нового. Исходный код уже изменён, но изменения не применились — нужен пересборка.

## Что уже сделано (в предыдущем ходе)

### 1. `src/hooks/useUpdateChecker.ts`
- Добавлен `import { toast } from 'sonner'`
- **Ошибка при проверке** (non-silent): вместо `setError('Ошибка проверки обновлений')` → `toast.error('Не удалось проверить обновления. Попробуйте позже.')` + `setStatus('idle')`
- **Обновлений нет** (non-silent): вместо `setError('Обновлений не найдено')` → `toast.info('Приложение уже имеет последнюю версию')`

### 2. `src/App.tsx`
- Добавлен `useEffect` который при `updateStatus === 'hasUpdate'` вызывает `setSettingsOpen(false)` — закрывает модалку настроек

1. **Ошибка** → toast вверху "Не удалось проверить обновления. Попробуйте позже."
