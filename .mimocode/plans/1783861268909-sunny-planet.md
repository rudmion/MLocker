# Исправление ошибки установки обновления

## Проблема
При нажатии "Обновить" появляется "ОШИБКА УСТАНОВКИ". Проверка версии работает, но установка падает.

## Причины (наиболее вероятные)

### 1. Нет артефактов обновления в релизе
Updater ищет `latest.json` по адресу:
```
https://github.com/rudmion/MLocker/releases/latest/download/latest.json
```
Если этот файл или `.msi.zip` отсутствуют — установка невозможна.

### 2. Dev-режим не поддерживает обновления
`yarn tauri dev` использует dev-сборку. Updater работает только с **собранными релизами** (`.msi`, `.exe`).

### 3. Проблема с подписью
Если `TAURI_SIGNING_PRIVATE_KEY` не настроен — подпись не совпадёт.

## Что сделать

### Шаг 1: Улучшить вывод ошибки (сделано)
В `useUpdateChecker.ts` теперь показывается реальное сообщение ошибки:
```typescript
const message = err instanceof Error ? err.message : String(err);
setError(message || 'Не удалось установить обновление');
```

### Шаг 2: Пересобрать приложение
```bash
# Остановить текущий dev-server (Ctrl+C)
yarn tauri dev
```

### Шаг 3: Проверить реальную ошибку
После пересборки нажать "Обновить" и посмотреть **точное сообщение** ошибки.

### Шаг 4: Проверить релиз
```bash
# Проверить последний релиз
gh release view

# Или в браузере:
# https://github.com/rudmion/MLocker/releases
```

Должны быть файлы:
- `latest.json`
- `MLocker_<version>_x64-setup.exe` (или `.msi`)
- `MLocker_<version>_x64-setup.exe.sig` (подпись)

### Шаг 5: Если артефактов нет — создать релиз
```bash
yarn bump <новая_версия>
```
Это создаст тег и запустит GitHub Actions, который соберёт и опубликует релиз с артефактами.

## Файлы
- `src/hooks/useUpdateChecker.ts` — обработка ошибок (уже исправлено)
- `src-tauri/tauri.conf.json` — конфиг updater
- `.github/workflows/release.yml` — сборка релизов
