# План улучшений логики обновления MLocker

## Текущая архитектура

```
Проверка:   useUpdateChecker → invoke("check_for_update") → GitHub API → compare_versions → UI
Скачивание: useUpdateChecker → invoke("check_for_update") → invoke("download_update") → temp file → pending_update.json
Установка:  user click → invoke("install_downloaded_update") → read pending_update.json → spawn .exe /S
```

Файлы: `src-tauri/src/updater.rs`, `src/hooks/useUpdateChecker.tsx`, `src/components/update/UpdateDialog.tsx`

```rust
// БЫЛО (строка 188):
pub async fn install_downloaded_update(app: AppHandle) -> Result<(), String> {

// СТАЛО:
pub async fn install_downloaded_update(app: AppHandle, file_path: String) -> Result<(), String> {
    let file_path = std::path::PathBuf::from(&file_path);

    if !file_path.exists() {
        return Err("Installer file not found".to_string());
    }

    // Запустить установщик
    #[cfg(target_os = "windows")]
    {
        std::process::Command::new(&file_path)
            .arg("/S")
            .spawn()
            .map_err(|e| format!("Failed to launch installer: {}", e))?;

        // Дать установщику время начаться, затем закрыть приложение
        std::thread::sleep(std::time::Duration::from_secs(2));
        app.exit(0);
    }

    #[cfg(target_os = "macos")]
    {
        // Для macOS — открыть DMG/APP
        std::process::Command::new("open")
            .arg(&file_path)
            .spawn()
            .map_err(|e| format!("Failed to open installer: {}", e))?;
        app.exit(0);
    }

    #[cfg(target_os = "linux")]
    {
        std::process::Command::new("xdg-open")
            .arg(&file_path)
            .spawn()
            .map_err(|e| format!("Failed to open installer: {}", e))?;
        app.exit(0);
    }

    Ok(())
}
```

fn cleanup_old_updates() {
    let temp = std::env::temp_dir();
    if let Ok(entries) = std::fs::read_dir(&temp) {
        for entry in entries.flatten() {
            let name = entry.file_name();
            let name_str = name.to_string_lossy();
            if name_str.starts_with("update_") && name_str.ends_with(".exe") {
                let _ = std::fs::remove_file(entry.path());
            }
        }
    }
}

## Изменение 10: Улучшить macOS/Linux установку

**Файл**: `src-tauri/src/updater.rs`

**Проблема**: `open -W file.dmg` не ставит приложение. `xdg-open file.deb` не ставит автоматически.

**Изменения**: для macOS использовать AppImage/zip (стандарт Tauri), для Linux — AppImage:

```rust
#[cfg(target_os = "macos")]
{
    // DMG требует hdiutil — открываем через Finder, пользователь сам ставит
    std::process::Command::new("open")
        .arg(&file_path)
        .spawn()
        .map_err(|e| format!("Failed to open installer: {}", e))?;

    // Показать инструкцию пользователю
    app.emit("update-instruction", serde_json::json!({
        "message": "Откройте DMG и перетащите MLocker в Applications"
    })).ok();
    app.exit(0);
}

#[cfg(target_os = "linux")]
{
    // AppImage — chmod +X и запуск
    if file_path.to_string_lossy().ends_with(".AppImage") {
        std::process::Command::new("chmod")
            .arg("+x")
            .arg(&file_path)
            .spawn()
            .map_err(|e| format!("Failed to chmod: {}", e))?;

        std::process::Command::new(&file_path)
            .spawn()
            .map_err(|e| format!("Failed to run AppImage: {}", e))?;
    } else {
        // .deb — установить через dpkg
        std::process::Command::new("pkexec")
            .args(["dpkg", "-i"])
            .arg(&file_path)
            .spawn()
            .map_err(|e| format!("Failed to install deb: {}", e))?;
    }
    app.exit(0);
}
```
