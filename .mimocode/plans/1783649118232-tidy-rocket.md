# Оптимизация процесса релиза MLocker

## Проблема

Текущий процесс релиза полностью ручной:
1. Обновить версию в `package.json` и `tauri.conf.json` (2 файла)
2. Запушить в `release` ветку
3. `npx tauri build`
4. Создать GitHub Release с тегом
5. Вручную загрузить `.msi`, `.exe` и `latest.json`

Это утомительно и подвержено ошибкам (забыл обновить версию, не загрузил latest.json, и т.д.).

---

## Решение: 3 уровня автоматизации

### Уровень 1: GitHub Actions (главное)

**Новый файл: `.github/workflows/release.yml`**

Workflow, который при пуше тега `v*` автоматически:
1. Собирает приложение для Windows (MSI + NSIS)
2. Создаёт GitHub Release
3. Загружает артефакты
4. Генерирует и загружает `latest.json` для updater

**Триггер:** `push: tags: ['v*']`

**Процесс для разработчика:**
```bash
# 1. Обновить версию (скрипт из Уровня 2)
npm run bump 0.2.0

# 2. Запушить
git push origin development

# 3. Создать тег и запустить релиз
git tag v0.2.0
git push origin v0.2.0
```

Всё остальное делает GitHub Actions автоматически.

---

### Уровень 2: Скрипт синхронизации версий

**Новый файл: `scripts/bump-version.js`**

Скрипт, который обновляет версию во всех файлах одновременно:
- `package.json` (version)
- `src-tauri/tauri.conf.json` (version)
- `src-tauri/Cargo.toml` (version)

**Использование:**
```bash
node scripts/bump-version.js 0.2.0
# Или через npm script:
npm run bump -- 0.2.0
```

**Добавить в `package.json`:**
```json
"scripts": {
  "bump": "node scripts/bump-version.js"
}
```

---

### Уровень 3: Автогенерация latest.json

В GitHub Actions workflow автоматически генерируется `latest.json` для tauri-plugin-updater:

```json
{
  "version": "0.2.0",
  "notes": "Изменения в этой версии...",
  "pubkey": "...",
  "platforms": {
    "windows-x86_64": {
      "signature": "...",
      "url": "https://github.com/.../MLocker_0.2.0_x64-setup.nsis.zip"
    }
  }
}
```

| Файл | Действие |
|------|----------|
| `.github/workflows/release.yml` | **Создать** — основной workflow сборки и релиза |
| `scripts/bump-version.js` | **Создать** — скрипт синхронизации версий |
| `package.json` | **Изменить** — добавить npm script `bump` |

## Детали workflow

### `.github/workflows/release.yml`

```yaml
name: Release

on:
  push:
    tags:
      - 'v*'

jobs:
  release:
    runs-on: ubuntu-latest
    permissions:
      contents: write
    steps:
      - uses: actions/checkout@v4

      - name: Setup Node.js
        uses: actions/setup-node@v4
        with:
          node-version: 20

      - name: Install Rust stable
        uses: dtolnay/rust-toolchain@stable

      - name: Install dependencies (ubuntu only)
        run: |
          sudo apt-get update
          sudo apt-get install -y libgtk-3-dev libwebkit2gtk-4.1-dev libappindicator3-dev librsvg2-dev patchelf

      - name: Install frontend dependencies
        run: yarn install

      - name: Build Tauri app
        uses: tauri-apps/tauri-action@v0
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
          TAURI_SIGNING_PRIVATE_KEY: ${{ secrets.TAURI_SIGNING_PRIVATE_KEY }}
          TAURI_SIGNING_PRIVATE_KEY_PASSWORD: ${{ secrets.TAURI_SIGNING_PRIVATE_KEY_PASSWORD }}
        with:
          tagName: ${{ github.ref_name }}
          releaseName: 'MLocker ${{ github.ref_name }}'
          releaseBody: 'См. CHANGELOG для деталей'
          releaseDraft: false
          prerelease: false
```

**Что делает `tauri-action`:**
- Собирает приложение для текущей ОС (нужен matrix для кросс-платформы)
- Подписывает артефакты ключом
- Создаёт GitHub Release
- Загружает артефакты
- Генерирует `latest.json` автоматически

### Кросс-платформенная сборка (matrix)

Для сборки на всех платформах:

```yaml
strategy:
  fail-fast: false
  matrix:
    include:
      - platform: 'windows-latest'
        target: 'x86_64-pc-windows-msvc'
      - platform: 'macos-latest'
        target: 'aarch64-apple-darwin'
      - platform: 'ubuntu-22.04'
        target: 'x86_64-unknown-linux-gnu'
```

## Новый процесс релиза (оптимизированный)

```bash
# 1. Обновить версию (одна команда вместо редактирования 2 файлов)
npm run bump -- 0.2.0

# 2. Запушить изменения
git add . && git commit -m "chore: bump version to 0.2.0"
git push origin development

# 3. Создать тег и запустить автоматический релиз
git tag v0.2.0
git push origin v0.2.0
```

**Больше не нужно:**
- Вручную редактировать `package.json` и `tauri.conf.json`
- Запускать `npx tauri build` локально
- Вручную создавать GitHub Release
- Вручную загружать артефакты
- Вручную создавать `latest.json`

Всё происходит автоматически через GitHub Actions.

---

## Верификация

1. Запустить `node scripts/bump-version.js 0.2.1` — проверить что версия обновилась в обоих файлах
2. Создать тестовый тег и запушить — проверить что workflow запустился
3. После завершения workflow проверить что Release создался с артефактами и `latest.json`
