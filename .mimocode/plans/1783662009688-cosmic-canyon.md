# Релиз обновления на GitHub

## Текущее состояние
- Ветка: `development`
- Текущая версия: `0.5.0`
- Remote: `https://github.com/rudmion/MLocker.git`
- Бранчи: `development`, `release`
- GitHub Actions: сборка и релиз при пуше тега `v*`

## Изменения в релизе
1. **Приватность кастомных полей** — кнопка Eye/EyeOff, `hidden: boolean` в JSON
2. **Фавиконка в инспекторе** — скачивание при вводе URL в поле "Ресурс"
3. **Дата обновления пароля** — отображение под полем пароля
4. **Убрана версия из sidebar** — теперь просто "MLocker"

## Пошаговый план

### 1. Бамп версии до 0.6.0
```bash
node scripts/bump-version.cjs 0.6.0
```
Скрипт обновит: `package.json`, `tauri.conf.json`, `Cargo.toml`

### 2. Закоммитить все изменения
```bash
git add .
git commit -m "feat: приватность кастомных полей, фавиконка в инспекторе, дата обновления пароля"
```

### 3. Запушить в development
```bash
git push origin development
```

### 4. Смерджить development → release
```bash
git checkout release
git merge development
git push origin release
```

### 5. Создать тег и запушить
```bash
git tag v0.6.0
git push origin v0.6.0
```

### 6. GitHub Actions автоматически
- Соберёт бандлы для Windows, macOS (aarch64), Linux
- Создаст GitHub Release с артефактами
- Подпишет бандлы если настроены секреты `TAURI_SIGNING_PRIVATE_KEY`

### 7. Вернуться на development
```bash
git checkout development
```

## Важно
- Секреты `TAURI_SIGNING_PRIVATE_KEY` и `TAURI_SIGNING_PRIVATE_KEY_PASSWORD` должны быть настроены в GitHub repo → Settings → Secrets
