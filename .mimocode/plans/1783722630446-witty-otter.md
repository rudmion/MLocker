# Фоновое обновление MLocker

## Цель
При нажатии "Обновить сейчас" — скачивание и установка происходят в фоне. После установки — уведомление с кнопкой "Перезагрузить". Перезагрузка через `process.restart()`.

## Текущий поток (проблемы)
1. `check_for_update` → показ `UpdateDialog`
2. Клик "Обновить сейчас" → скачивание в temp → **запуск нативного установщика с GUI** (показывает своё окно)
3. Toast: "Установите обновление и перезапустите" — ручное действие

## Целевой поток
1. Клик "Обновить сейчас" → скачивание в temp (с прогрессом)
2. Установщик запускается **тихо** (`/S` для NSIS на Windows)
3. Установщик заменяет файлы в фоне (locked .exe переименовывается, новые файлы ставятся)
4. После завершения установщика → toast: "Обновление установлено. Перезагрузите приложение." с кнопкой
5. Клик "Перезагрузить" → `app.restart()` (Tauri API)

## Изменения

### 1. Backend: `src-tauri/src/updater.rs`

**Модифицировать `download_and_install_update`** (строки 117-203):

- На Windows: передать флаг `/S` в `Command::new(&file_path).arg("/S")` — тихий режим NSIS
- На macOS: добавить флаг `--quiet` если поддерживается, или оставить `open` (macOS установщики обычно тихие)
- На Linux: для `.deb` использовать `dpkg -i` с флагом, для AppImage — просто скопировать

**Добавить новую команду `restart_app`**:
```rust
#[tauri::command]
pub fn restart_app(app: AppHandle) {
    app.restart();
}
```

### 2. Frontend hook: `src/hooks/useUpdateChecker.tsx`

**Добавить состояние `updateInstalled`** в `UpdateState`:
```typescript
updateInstalled: boolean;  // установка завершена, ждём перезагрузки
```

**Модифицировать `installUpdate`** (строки 99-148):
- После завершения `download_and_install_update` → установить `updateInstalled: true`
- Показать toast с кнопкой "Перезагрузить" (вместо текущего текста "Установите обновление")
- Toast не закрывается автоматически (или long duration)

**Добавить функцию `restartApp`**:
```typescript
const restartApp = useCallback(async () => {
  await invoke('restart_app');
}, []);
```

**Экспортировать** `restartApp` и `updateInstalled`.

### 3. Уведомления: `src/lib/notifications.tsx`

**Добавить** `updateInstalled` нотификацию:
```typescript
updateInstalled: (onRestart: () => void) =>
  toast.success('Обновление установлено. Перезагрузите приложение.', {
    icon: <RotateCw className="text-green-500 pe-1" />,
    duration: Infinity,  // не закрывается автоматически
    action: {
      label: 'Перезагрузить',
      onClick: onRestart,
    },
  }),
```

### 4. App root: `src/App.tsx`

- Подключить `restartApp` и `updateInstalled` из хука
- Передать `restartApp` в `UpdateDialog` или вызывать нотификацию

### 5. UpdateDialog: `src/components/update/UpdateDialog.tsx`

- После завершения установки (когда `downloading` было true и теперь `updateInstalled` true) — закрыть диалог
- Показать toast через `notifications.updateInstalled(restartApp)`

## Верификация

1. `cargo build` в `src-tauri/` — убедиться что Rust код компилируется
2. `npm run build` (или `bun run build`) — убедиться что фронтенд компилируется
3. Ручное тестирование:
   - Запустить приложение
   - Нажать "Проверить обновления" в настройках
   - Если доступно обновление → нажать "Обновить сейчас"
   - Проверить что скачивание идёт с прогрессом
   - Проверить что установщик НЕ показывает окно
   - Проверить что появляется toast с кнопкой "Перезагрузить"
   - Нажать "Перезагрузить" → приложение перезапускается с новой версией
