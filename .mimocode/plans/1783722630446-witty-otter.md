# Исправление: перезапуск + правильный путь установки

## Проблемы
1. **Перезапуск**: приложение закрывалось, но не открывалось заново
2. **Путь**: NSIS установщик ставил приложение не в тот каталог

## Причины
1. **Перезапуск**: NSIS установщик (`/S`) запущен при скачивании, потом `app.restart()` вызван повторно — два конфликтующих процесса убивают приложение
2. **Путь**: NSIS с `/S` без флага `/D=` использует дефолтный путь, а не выбранный пользователем

## Решение
1. **Разделить** скачивание и установку — не запускать установщик при скачивании
2. **Передать путь** через `/D=<текущий_каталог>` — NSIS установит в правильное место
3. **NSIS сам перезапускает** приложение после установки — убрать `app.restart()`

## Изменения

### 1. Backend: `src-tauri/src/updater.rs`

**Убрать** `restart_app` (не нужен — NSIS делает перезапуск).

**Разделить `download_and_install_update` на две команды:**

**`download_update`** — только скачивание (строки 116-168 текущего кода):
```rust
#[tauri::command]
pub async fn download_update(app: AppHandle, url: String) -> Result<String, String> {
    // скачивание в temp_dir с прогрессом (как сейчас)
    // НЕ запускает установщик
    // Сохраняет путь к файлу в app_data_dir/pending_update.json
    Ok(file_path.to_string_lossy().to_string())
}
```

**`install_downloaded_update`** — запуск установщика:
```rust
#[tauri::command]
pub async fn install_downloaded_update(app: AppHandle) -> Result<(), String> {
    // 1. Прочитать путь из app_data_dir/pending_update.json
    // 2. Получить текущий каталог приложения:
    //    let exe_path = std::env::current_exe()?;
    //    let install_dir = exe_path.parent()?;
    // 3. Запустить NSIS с флагами:
    //    /S — тихий режим
    //    /D=<install_dir> — установить в текущий каталог
    // 4. NSIS закроет приложение, заменит файлы, запустит новую версию
}
```

### 2. Frontend hook: `src/hooks/useUpdateChecker.tsx`

**Модифицировать `installUpdate`:**
- Вызывать `download_update` (только скачивание)
- После скачивания → показать toast с кнопкой "Перезагрузить"

**Заменить `restartApp` на `restartWithInstall`:**
```typescript
const restartWithInstall = useCallback(async () => {
  await invoke('install_downloaded_update');
}, []);
```

### 3. Уведомления: `src/lib/notifications.tsx`

Обновить `updateInstalled`:
```typescript
updateInstalled: (onInstallAndRestart: () => void) =>
  toast.success('Обновление загружено. Перезагрузите для установки.', {
    icon: <RotateCw className="text-green-500 pe-1" />,
    duration: 20000,
    action: {
      label: 'Перезагрузить',
      onClick: onInstallAndRestart,
    },
  }),
```

### 4. App.tsx

Использовать `restartWithInstall` вместо `restartApp`:
```typescript
notifications.updateInstalled(restartWithInstall);
```

### 5. `src-tauri/src/main.rs`

Зарегистрировать `download_update` и `install_downloaded_update`.
Убрать `download_and_install_update` и `restart_app`.

1. `cargo check` — Rust компилируется

3. Ручное тестирование:
   - Клик "Обновить сейчас" → скачивание с прогрессом (без запуска установщика)
